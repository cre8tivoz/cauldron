# Cauldron directions v2

Ten fictional businesses, designed as distinct starting points. Real-site notes inform the ideas; they are not templates to copy. Gradient Deck notes are reference-only.

1. **Long Lunch** — cafe / restaurant; serif, editorial columns, soft, light warm, balanced, subtle. References: montecafe.com.au, busybeehoney.com.
2. **Solid Ground** — trades / builders; display, modular grid, sharp, light warm, dense, still. References: quechua-lookbook.com, ray.care.
3. **Good Measure** — health / clinic / physio; geometric, centred classic, pill, light cool, airy, subtle. References: kihealth.com, ray.care.
4. **Soft Ritual** — wellness / beauty / skincare; serif, asymmetric, sharp, light warm, airy, still. References: eclobeauty.com, aesop.com.
5. **Big Idea** — creative studio / agency; display, asymmetric, organic, saturated, dense, lively. References: thelinestudio.com, toyfight.co.
6. **Quiet Frame** — photographer / artist portfolio; grotesk, full-bleed image-led, sharp, monochrome+accent, airy, still. References: milkinside.com, studiofreight.com.
7. **Open House** — gallery / arts / theatre / festival; serif, modular grid, sharp, light cool, dense, subtle. References: postery.com, mubi.com.
8. **The Edit** — boutique retail / fashion; serif, full-bleed image-led, sharp, monochrome+accent, balanced, subtle. References: fearofgod.com, comingsoonnewyork.com.
9. **Little Neighbours** — kids / family / community; geometric, modular grid, organic, saturated, balanced, lively. References: busybeehoney.com, rascalsbaby.com.
10. **After Hours** — music / nightlife / venue; display, editorial columns, pill, dark, dense, lively. References: tiempo.fitness, poolsuite.net.

## Limitations

The board is a static concept, not production templates. Abstract CSS art is a stand-in for commissioned photography or artwork. A human must assess visual distinctness and the full taste-test suite in a browser.
