# Cauldron v1 starter set

Decided by Claudia on 7 Nov 2026, on Billy's instruction to make taste-driven decisions. Sources are Billy's own references from his `WEB BUILDER IDEAS` note. Open Design is not used.

## Design directions: 7, from Design Bites real-site design files (MIT)

Each one learns from a real live site, which is linked so you can see it. Every one has a different colour world; only one is warm cream.

| For | Learns from | The look |
|---|---|---|
| Cafés and restaurants | [montecafe.com.au](https://montecafe.com.au) | Mediterranean warmth: cream `#f8f4e9`, terracotta `#b84b30`, deep red `#5f1d1a` |
| Health, physio and wellness | [kihealth.com](https://kihealth.com) | Calm, not clinical: warm white `#FFFCF8`, deep forest green `#003F3C`, soft yellow highlights |
| Trades and builders | [quechua-lookbook.com](https://quechua-lookbook.com) | Practical workwear: charcoal, bone, stone and toffee |
| Creative studios | [thelinestudio.com](https://thelinestudio.com) | Cool cinematic silver `rgb(221,222,226)`, near-black type, one red-orange signal, oversized lettering |
| Boutique retail and fashion | [comingsoonnewyork.com](https://comingsoonnewyork.com) | Editorial white with ink `#101820` and one vivid indigo `#4a4af4` |
| Arts, film and venues | [siena.film](https://siena.film) | Dark-theatre black with antique-ivory type |
| Makers, food producers and families | [busybeehoney.com](https://busybeehoney.com) | Heritage label: folksy, warm, playful, with crafted type |

**Notes:**
- These sites use paid fonts, so each direction gets a free (SIL OFL) equivalent when it's built.
- Arts/film uses pure black, which the taste rules flag. Per Billy's rule, the direction wins and Cauldron explains why.

## Components: 5 built in, plus a shelf of links

**Built in** (ThreeUI Community, MIT, credited; converted to plain Astro where possible):
1. Editorial intro section
2. Newsletter footer
3. Glowing call-to-action button
4. Heading text-reveal
5. Woven-cloth texture background (atelier/washi)

**Left out on taste:**
- The 3D gallery and spark badge: heavy to build, and too gimmicky for small-business sites.
- ThreeUI's novelty 3D scenes.

**Links shelf, browsable inside Cauldron** (no reuse licence, so link only): Unsection, Lander blocks, Gradient Deck, mkdir.directory, Subframe Motion, Prompt Motion, React Bits, OriginKit and Lexington Themes.

**Guidance behind the taste rules** (not components): Superdesign skill, Stageshow, Design With Intent and Templens.
