# Library components are copied into the site

When someone adds a component from Cauldron's library, it's copied into their site as normal, editable files that the site owns. It's not linked from a shared Cauldron package. The site keeps working with or without Cauldron, and people can change a component freely. The trade-off: improvements to the library don't flow into components that were already added. Decided by Billy, 6 Nov 2026.
