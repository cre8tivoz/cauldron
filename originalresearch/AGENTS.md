# Cauldron Astro

## Agent skills

### Issue tracker

Issues and specs live as local markdown files under `.scratch/<feature-slug>/`. See `docs/agents/issue-tracker.md`.

Application findings are tracked in the sibling app's `.scratch/cauldron-v1/spec.md` and `issues/`. Read `START-HERE.md`, the agreed plan, approved taste tests, starter set, relevant ADRs and glossary before work. Use research as supporting evidence; preserve the agreed requirements. Application development remains paused during the documentation audit.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`, recorded as `Status:` lines in each issue file. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root, created lazily. See `docs/agents/domain.md`.
