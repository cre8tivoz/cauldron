# Studied code and research are used as reference, never copied

Everything gathered in research (source repositories, REA analysis of Stacki, Sitereal and Zeku, and our written assessments) is kept and used to understand how things work and to inform our own design. Cauldron's code is our own; no code from those products is copied into the Cauldron repository. **Scope:** this covers Cauldron's application code. The component library may include third-party pieces only where their licence allows (for example ThreeUI, MIT), with attribution; everything else is a link (plan 4.3, ADR 0008). This rule also covers Billy's own Cauldron OS: its taste layer is rewritten fresh in Cauldron, using Cauldron OS as reference only. Decided by Billy, 6 Nov 2026, replacing the earlier recommendation to delete the extracted Sitereal code.
